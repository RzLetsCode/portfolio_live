Time To First Token (TTFT)
TTFT is the latency from request arrival to the first generated token, combining queueing, prefill, and the initial decode. In enterprise serving, this is the primary KPI for perceived responsiveness.
Target: < 250ms (interactive chat)
If TTFT scales with prompt length, you are prefill-bound.

3. Prefill KV cache (tokens → KV blocks)
During prefill, the model runs attention over the tokens and builds a key–value (KV) cache. Each block below represents stored KV for a segment of the prompt, filling in the same Prefill window.
