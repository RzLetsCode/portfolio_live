Question 1

Vector Magnitude & Normalization

Problem: Given the 3D vector $\mathbf{a} = (3, -4, 12)$:

  1. Calculate its magnitude $\|\mathbf{a}\|$.
  2. Find the normalized unit vector $\hat{\mathbf{a}}$.
  3. Verify that the magnitude of $\hat{\mathbf{a}}$ equals $1$.

Mathematical Solution:

  1. Magnitude Calculation: $$\|\mathbf{a}\| = \sqrt{a_1^2 + a_2^2 + a_3^2} = \sqrt{3^2 + (-4)^2 + 12^2} = \sqrt{9 + 16 + 144} = \sqrt{169} = 13$$
  2. Normalization: $$\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|} = \frac{1}{13}(3, -4, 12) = \left(\frac{3}{13}, -\frac{4}{13}, \frac{12}{13}\right)$$
  3. Verification: $$\|\hat{\mathbf{a}}\| = \sqrt{\left(\frac{3}{13}\right)^2 + \left(-\frac{4}{13}\right)^2 + \left(\frac{12}{13}\right)^2} = \sqrt{\frac{9 + 16 + 144}{169}} = \sqrt{\frac{169}{169}} = 1$$

Question 2

Vector Equality & Location Independence

Problem: Vector $\mathbf{v}_1$ is drawn from point $A(1, 2)$ to $B(4, 6)$. Vector $\mathbf{v}_2$ is drawn from point $C(-2, -1)$ to $D(1, 3)$.

  1. Find the components of $\mathbf{v}_1$ and $\mathbf{v}_2$.
  2. Are $\mathbf{v}_1$ and $\mathbf{v}_2$ equal? Explain why or why not using displacement.

Mathematical Solution:

  1. Displacement Components: $$\mathbf{v}_1 = B - A = (4 - 1, 6 - 2) = (3, 4)$$ $$\mathbf{v}_2 = D - C = (1 - (-2), 3 - (-1)) = (3, 4)$$
  2. Equality Check: $$\mathbf{v}_1 = \mathbf{v}_2 \iff (v_{1,x}, v_{1,y}) = (v_{2,x}, v_{2,y})$$ Since both vectors have identical components $(3, 4)$, $\mathbf{v}_1 = \mathbf{v}_2$. Vectors represent pure displacement regardless of starting location.

Question 3

Parallel vs. Orthogonal Vectors

Problem: Given vectors $\mathbf{u} = (2, 4)$, $\mathbf{v} = (-4, -8)$, and $\mathbf{w} = (-4, 2)$:

  1. Determine if $\mathbf{u}$ and $\mathbf{v}$ are parallel, orthogonal, or neither.
  2. Determine if $\mathbf{u}$ and $\mathbf{w}$ are parallel, orthogonal, or neither.

Mathematical Solution:

  1. Testing $\mathbf{u}$ and $\mathbf{v}$: $$\mathbf{v} = -2\mathbf{u} \implies \text{Parallel (opposite direction)}$$
  2. Testing $\mathbf{u}$ and $\mathbf{w}$: $$\mathbf{u} \cdot \mathbf{w} = (2)(-4) + (4)(2) = -8 + 8 = 0 \implies \text{Orthogonal (90° angle)}$$

Question 4

Linear Dependence vs. Independence

Problem: Consider vectors $\mathbf{a} = (1, 2)$, $\mathbf{b} = (3, 1)$, and $\mathbf{c} = (5, 5)$.

  1. Prove whether $\mathbf{c}$ can be expressed as a linear combination $\mathbf{c} = c_1\mathbf{a} + c_2\mathbf{b}$.
  2. Is the set $\{\mathbf{a}, \mathbf{b}, \mathbf{c}\}$ linearly dependent or independent?

Mathematical Solution:

  1. Linear Combination: $$(5, 5) = 2(1, 2) + 1(3, 1) \implies \mathbf{c} = 2\mathbf{a} + \mathbf{b}$$
  2. Conclusion: The set $\{\mathbf{a}, \mathbf{b}, \mathbf{c}\}$ is linearly dependent because $\mathbf{c}$ can be synthesized entirely from $\mathbf{a}$ and $\mathbf{b}$.

Question 5

Sparse Vectors & Memory Efficiency

Problem: Given the feature vector $\mathbf{s} = [0, 0, 4.5, 0, 0, 0, -1.2, 0, 0, 0.8]$:

  1. Determine whether this vector is sparse or dense.
  2. Calculate its sparsity ratio (percentage of zero entries).

Mathematical Solution:

  1. Classification: The vector is sparse (7 out of 10 elements are zero).
  2. Sparsity Ratio: $$\text{Sparsity Ratio} = \frac{7}{10} = 70\%$$
