Worked Problem: Vector Magnitudes, Dot Product & Inverse Cosine

📝 Problem Statement

Given two vectors:

$$\mathbf{a} = [3, 4] \quad \text{and} \quad \mathbf{b} = [4, 3]$$
  1. Compute the magnitudes $\|\mathbf{a}\|$ and $\|\mathbf{b}\|$.
  2. Compute the dot product $\mathbf{a} \cdot \mathbf{b}$.
  3. Find $\cos(\theta)$ and calculate the angle $\theta$ between them step-by-step.

📐 Step-by-Step Solution

1 Compute the Magnitudes

The magnitude of a vector $\mathbf{v} = [v_1, v_2]$ is given by $\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2}$:

  • Magnitude of $\mathbf{a} = [3, 4]$: $$\|\mathbf{a}\| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$
  • Magnitude of $\mathbf{b} = [4, 3]$: $$\|\mathbf{b}\| = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5$$

2 Compute the Dot Product

Multiply corresponding components and sum them up:

$$\mathbf{a} \cdot \mathbf{b} = (3 \times 4) + (4 \times 3) = 12 + 12 = 24$$

3 Find $\cos(\theta)$ and the Angle $\theta$

Rearrange the geometric dot product formula $\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\| \cos(\theta)$:

$$\cos(\theta) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \|\mathbf{b}\|} = \frac{24}{5 \times 5} = \frac{24}{25} = 0.96$$

Take the inverse cosine ($\arccos$) to solve for $\theta$:

$$\theta = \arccos(0.96) \approx 16.26^\circ \quad \text{(or } \approx 0.2838 \text{ radians)}$$

💡 Breakdown: How is $\arccos(0.96)$ Calculated?

Core Concept: The inverse cosine function ($\arccos$ or $\cos^{-1}$) asks: "What angle $\theta$ produces a cosine value equal to 0.96?"

Method 1: Scientific Calculator / Code

Because $0.96$ isn't a standard unit-circle angle, computational tools use high-precision lookup routines:

  • Calculator: Set mode to Degrees $\rightarrow$ Press SHIFT/2nd $\rightarrow$ Press cos ($\cos^{-1}$) $\rightarrow$ Type 0.96 $\rightarrow$ Result: 16.26°
import math

# Inverse cosine returns radians in Python
radians = math.acos(0.96)
degrees = math.degrees(radians)

print(f"Radians: {radians:.4f}")  # Output: 0.2838
print(f"Degrees: {degrees:.2f}°")   # Output: 16.26°

Method 2: Mathematical Approximation (Taylor Series)

For small angles, we can approximate $\cos(\theta)$ near 0 using the Taylor series:

$$\cos(\theta) \approx 1 - \frac{\theta^2}{2}$$

Setting this equal to $0.96$ and solving for $\theta$ step-by-step:

  1. Subtract $1$ from both sides: $$-\frac{\theta^2}{2} = 0.96 - 1 = -0.04$$
  2. Multiply both sides by $-2$: $$\theta^2 = 0.08$$
  3. Take the square root to get radians: $$\theta = \sqrt{0.08} \approx 0.2828 \text{ radians}$$
  4. Convert radians to degrees ($\text{Radians} \times \frac{180^\circ}{\pi}$): $$\theta = 0.2828 \times \left(\frac{180^\circ}{3.14159}\right) \approx 16.20^\circ$$

Notice how close $16.20^\circ$ is to the exact answer of $16.26^\circ$ using just a simple 2-term approximation!
