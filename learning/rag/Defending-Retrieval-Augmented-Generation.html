The Core Challenge

The fundamental vulnerability in RAG systems is Instruction and Data Conflation. LLMs process system instructions and retrieved external data as a single sequence of tokens, allowing malicious content to overwrite developer policies.

📊 Impact Overview

Taxonomy of Attack Vectors

Prompt Control-Flow Integrity (PCFI)

To resolve conflation, we treat prompts as structured, prioritized graphs rather than flat strings. Higher priority levels ($\mathcal{P}_0$) permanently supersede lower levels ($\mathcal{P}_3$).

$\mathcal{P}_0$: System Core Directives Immutable
$\mathcal{P}_1$: Developer Task Rules High
$\mathcal{P}_2$: User Query Constraints Medium
$\mathcal{P}_3$: Retrieved Context (Untrusted) Lowest
"If a token in $\mathcal{P}_3$ attempts to redefine a rule in $\mathcal{P}_0$, the middleware identifies a priority violation."
