High-Dimensional Vector Spaces & Recommendation Systems

🤖 Applied Machine Learning

🎯 Problem Statement

In recommendation engines, similarity is calculated in high-dimensional feature spaces. Let document vectors be:

$$\mathbf{d}_1 = [2, 0, 1, 3, 0] \quad \text{and} \quad \mathbf{d}_2 = [4, 0, 2, 6, 0]$$
  1. Algebraic Proof: Prove mathematically that scaling a vector by any positive scalar $c > 0$ does not change its cosine similarity with another vector $\mathbf{u}$.
  2. Document Analysis: Compute $\cos(\theta)$ between $\mathbf{d}_1$ and $\mathbf{d}_2$. What does this result tell us about document recommendations?

💡 Solution Key

1 Algebraic Proof of Scale Invariance

Let vector $\mathbf{w} = c\mathbf{v}$, where $c > 0$ is a positive scalar. We calculate the cosine similarity between vector $\mathbf{u}$ and scaled vector $\mathbf{w}$ using the dot product formula:

$$\cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{w}}{\|\mathbf{u}\|\|\mathbf{w}\|} = \frac{\mathbf{u} \cdot (c\mathbf{v})}{\|\mathbf{u}\| \|c\mathbf{v}\|}$$

Using the properties of vector scaling where $c > 0$:

  • The dot product with a scalar constant is associative: $\mathbf{u} \cdot (c\mathbf{v}) = c(\mathbf{u} \cdot \mathbf{v})$
  • The norm (magnitude) of a scaled vector extracts the positive factor: $\|c\mathbf{v}\| = c\|\mathbf{v}\|$

Substituting these properties back into our expression:

$$\cos(\theta) = \frac{c(\mathbf{u} \cdot \mathbf{v})}{\|\mathbf{u}\| \cdot c\|\mathbf{v}\|}$$

Since $c > 0$, we can cancel out the scalar constant $c$ from both the numerator and the denominator entirely:

$$\cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$$

Conclusion: The positive scalar $c$ cancels out completely. This proves that magnitude scaling has zero effect on cosine similarity. $\blacksquare$

2 Document Analysis & Computation

Inspecting the given document vectors $\mathbf{d}_1$ and $\mathbf{d}_2$:

$$\mathbf{d}_1 = [2, 0, 1, 3, 0]$$ $$\mathbf{d}_2 = [4, 0, 2, 6, 0] = 2 \times [2, 0, 1, 3, 0] = 2\mathbf{d}_1$$

Notice that $\mathbf{d}_2$ is a direct scalar multiple of $\mathbf{d}_1$ with $c = 2 > 0$. According to our scale invariance proof:

$$\cos(\theta) = 1.0 \implies \theta = 0^\circ$$
🤖 Machine Learning Interpretation:
Document 2 contains the exact same proportion of keywords as Document 1, but is simply twice as long. A cosine similarity of $1.0$ ($\theta = 0^\circ$) correctly identifies them as conceptually identical topics despite the length difference. This is why search engines and recommender systems prefer Cosine Similarity over standard Euclidean Distance for document embeddings.

🐍 Verification Code (NumPy)

import numpy as np

d1 = np.array([2, 0, 1, 3, 0])
d2 = np.array([4, 0, 2, 6, 0])

# Compute Cosine Similarity
cos_sim = np.dot(d1, d2) / (np.linalg.norm(d1) * np.linalg.norm(d2))
angle_deg = np.degrees(np.arccos(np.clip(cos_sim, -1.0, 1.0)))

print(f"Cosine Similarity: {cos_sim:.4f}")  # Output: 1.0000
print(f"Angle (θ): {angle_deg:.2f}°")        # Output: 0.00°
